# Keystone

A focused macOS-style library for saving and reusing prompts, snippets, design files, and other working artifacts across apps.

## Run it

Open `index.html` in a browser. No build step or dependencies are required.

## Included

- Searchable library with collections for prompts, design files, and snippets
- Detail view with copy-to-clipboard for use in Terminal, an IDE, or a chat app
- Add and edit items through the `New item` flow
- Favorite items and filter by collection
- Attached-file presentation for design artifacts
- Keyboard shortcut: `⌘ K` focuses search
- Local persistence using `localStorage`
- Responsive layout that compresses into a compact sidebar on smaller windows
